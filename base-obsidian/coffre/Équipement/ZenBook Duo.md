# ZenBook Duo

## En bref
C'est le PC portable principal (nom réseau ZenBook-Jérôme) : un ASUS ZenBook Duo **UX8406CA** sous Windows 11 Pro. Il **n'a pas de carte graphique Nvidia**.

## Caractéristiques (relevées le 12/11/2026 dans MyASUS et LM Studio)
- Système : Windows 11 Professionnel 64 bits, version 10.0.26300.
- Firmware : UX8406CA.309 (publié le 26/06/2025).
- Processeur : Intel Core Ultra 9 285H (x86_64, AVX2).
- Puce graphique : **Intel Arc 140T** intégrée. LM Studio y voit 17,88 Go de VRAM partagée via Vulkan.
- Mémoire : 32 Go LPDDR5X à 7 467 MHz, souvent utilisée à environ 76 %.
- Stockage : SSD WD PC SN5000S de 953 Go. Il restait **43 Go libres** sur C: le 12/11.
- Wi-Fi : Intel Wi-Fi 7 BE201.
